# HA8 + QD4310 机械适配模型说明

版本：数字装配版 v1  
日期：2026-09-18  
状态：参数化模型与局部几何校验已完成，实体首件验证未完成。

## 设计目标

- 腿部四个关节使用 `HA8-U25H-M ×4`。
- 左右轮端使用 `QD4310 ×2` 外转子直驱。
- 尽量保持灯哥原结构的腿长、局部关节中心、轮轴中心和约 `Ø66×29.9 mm` 车轮包络。
- 原始 STL 和官方 STEP/PDF/DWG 均未覆盖或改写。

## 坐标系

- 机器人 `X` 向前、`Y` 向左、`Z` 向上。
- 关节和轮端局部 `+Z` 为旋转轴正方向。
- 左右件由同一参数化实体沿 XZ 平面镜像生成。
- 目前只能验证局部中心保持；原整机绝对装配坐标无法由孤立 STL 唯一恢复。

## 输出目录

- `01_参数化源文件/`：CadQuery/Python 源码与锁定依赖。
- `02_STEP装配与零件/`：26 个制造件 STEP 和 3 个装配 STEP。
- `03_STL打印件/`：26 个 STL。
- `04_装配检查/`：输入审计、几何、碰撞、导出验证和 SHA256。
- `05_设计说明/`：本说明、BOM 和实物待复测项。

## 替代关系

- `HA8_舵机接口1~4_v1` 替代原 `舵机接口1~4.stl` 的接口功能。
- `HA8_外固定1~4_v1` 与 `HA8_盖板1~4_v1` 是围绕 HA8 包络的局部适配件。
- `QD4310_电机固定X1/X2_v1` 替代原 2208 电机固定功能。
- `QD4310_轮毂X1/X2_v1` 与 `QD4310_轮固定X1/X2_v1` 对应 QD4310 外转子直驱和原轮胎保持功能。

## 关键装配原则

1. HA8 输出侧必须使用 FashionStar 官方金属 25T 八孔主舵盘；打印件不包含也不得承担 25T 花键功能。
2. HA8 背面 M3 只连接可更换金属隔套/轴承/衬套，不让普通打印孔作为高负载旋转轴承面。
3. QD4310 定子以 4×M2.5、BCD Ø38.5 固定到支架，外转子驱动车轮。
4. QD4310 转子 8×M3 的 BCD 在官方公开资料中未唯一确认。当前轮毂孔系是明确标注的临时参数，实测前不得作为最终加工定稿。
5. 螺钉沿局部 `+Z/-Z` 方向装入；先安装电机/舵机及线束，再安装外侧盖板和轮固定件。

## 打印建议

- 承力件优先 PA-CF 或 PETG-CF；首件可用低成本材料验证孔位和拆装顺序。
- 适配盘、定子支架尽量让主要贴合面平放；避免层间方向承担主要剪切载荷。
- 先打印孔径/台阶校准件，再统一调整参数化补偿。
- 复测后修改参数并重新导出，不直接编辑 STL 网格。

## 构建与校验

```bash
env -u PYTHONPATH .venv-mechanical/bin/python '机械资料/03_适配模型/01_参数化源文件/build_all.py'
env -u PYTHONPATH .venv-mechanical/bin/pytest tests/mechanical_adapter -v
sha256sum -c '机械资料/03_适配模型/04_装配检查/SHA256SUMS.txt'
```

最近一次校验：92 个测试通过；26 个 STL 均非空、封闭、流形、法向一致；STEP/STL 包围盒差异不超过 0.05 mm；MeshLabServer 二次读取通过。

## 限制

- QD4310 转子孔 BCD、HA8 被动嵌件尺寸、原整机绝对装配坐标仍未解析。
- 因此完整实体碰撞最小间隙没有被伪造为已验证数值；`collision_report.json` 明确记录未验证项。
- 未完成实物首件复测前，本套模型仅为“数字装配版 v1”。
