# WheelBot ROS 2 workspace

On Raspberry Pi Ubuntu 24.04 ARM64, install ROS 2 Jazzy `ros-base`, `colcon`, `rosdep`, `vcstool`, `pyserial`, `git`, and `cmake`, source the Jazzy environment, then run `colcon build --symlink-install` from this directory. The first bridge contract is newline-delimited `PING`/`PONG`; actuator and sensor state messages come later.
