# 轮足机器人机械原始资料下载实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从公开官方/开源来源下载 StackForce 灯哥小型轮足机器人和 FashionStar HA8-U25H-M 相关机械资料，按中文目录保存原始文件，生成来源说明、校验结果和最终 ZIP。

**Architecture:** 先以 Git 仓库和官方直链为主获取原始文件，所有来源先进入临时下载区并记录 URL、版本/提交和 SHA256，再复制到最终中文目录。对 FashionStar 资料按“明确 HA8-U25H-M”“同尺寸系列参考”“未找到”三类归档，禁止转换、重建、覆盖同名文件。

**Tech Stack:** `git`, `curl`/`wget`, `unzip`, `find`, `sha256sum`, `zip`, Markdown。

**Spec:** 用户在当前对话中提供的“轮足机器人机械公开资料下载、整理、校验和打包”要求。

## Global Constraints

- 只使用公开官方或开源资源。
- 不生成、转换、重建或修改任何 STL、STEP、STP、DWG、PDF、URDF、mesh、配置文件。
- 保留原始文件名和原始内容；同名文件不静默覆盖。
- StackForce 原始 STL 与 Seeed 官方 URDF/STL 包分开保存。
- HA8-U25H-M 必须与 HA8-U25-M 7.4V 区分。
- QD4310、HA8 适配属于后续工作，本次不修改任何 CAD。
- 下载日期统一记录为 2026-09-13（Asia/Shanghai）。
