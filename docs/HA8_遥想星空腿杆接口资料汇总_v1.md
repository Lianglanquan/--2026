## 1. 当前要解决的问题
+
遥想星空 `Skythinker616/foc-wheel-legged-robot` 原结构的关节模块使用 4010 电机。当前目标是用华馨京 / FashionStar `HA8-U25H-M` 总线舵机替换原 4010 关节，并让 HA8 的原厂金属 25T 舵盘与遥想星空腿杆可靠连接。
+
本阶段只处理 HA8 关节接口，不确定 QD4310 轮端执行器，不修改车身、电池架、上盖和轮胎。

## 4. 遥想星空腿部数据
+
### 4.1 MATLAB 杆长参数
+
`matlab/leg_func_calc.m` 中的腿部杆长为：
+
```matlab
l1 = 0.05;   % 50 mm
l2 = 0.105;  % 105 mm
l3 = l2;     % 105 mm
l4 = l1;     % 50 mm
l5 = 0.06;   % 60 mm
```
+
对应关系：
+
- `l1 = l4 = 50 mm`：两侧短连杆 / 电机侧几何杆长；
- `l2 = l3 = 105 mm`：两根长腿杆几何杆长；
- `l5 = 60 mm`：基座两侧连接点的几何间距参数；
- `L0` 虚拟腿长控制拟合范围：`40–140 mm`；
- `L0 = 70 mm` 是常用标称腿长参考值。
+
这些是运动学模型参数，不等于每个打印件的外轮廓尺寸。腿杆端部法兰需要继续从原始 SolidWorks / STEP 总装测量。
+
### 4.2 URDF 关节基准
+
本地 URDF/CSV 给出的关节轴主要沿 Y 轴。轮轴相对小腿关节的局部平移约为 100 mm，当前记录值约 `99.98 mm`。该值是 URDF 原点链推导的参考，整机绝对装配位置仍需总装 STEP 复核。

## 5. 本次确定的 HA8 到腿杆连接方案
+
### 5.1 两套接口必须分开
+
1. **HA8 本体固定接口**
   - HA8 两侧安装耳插入或贴合 3D 打印外固定支架。
   - 外固定支架通过 `4 × Ø4.3 mm` 安装耳孔用螺钉固定 HA8 本体。
   - 这套接口只负责把舵机壳体固定到腿部/车身支撑结构，不能承担腿杆输出连接。
+
2. **HA8 输出接口**
   - HA8 顶部安装原厂金属 25T 八孔主舵盘。
   - 遥想星空腿杆关节端不再沿用原 4010 电机输出端，而是重新设计为带法兰的腿杆端部。
   - 腿杆法兰的八个通孔按官方金属舵盘的八孔位置布置，与舵盘同轴。
   - 螺钉穿过金属舵盘周向孔，把金属舵盘和腿杆端部法兰锁紧。
   - 扭矩传递路径为：HA8 25T 花键 → 金属舵盘 → 周向螺钉/法兰贴合面 → 遥想星空腿杆。
   - 腿杆不能直接锁在 HA8 塑料/铝合金壳体上，不能把一个普通圆柱体当成输出接口。
+
### 5.2 腿杆端部法兰应该画成什么
+
工程图应至少包含：
+
- 遥想星空大腿或小腿杆本体的关节端截面；
- 与官方金属舵盘贴合的法兰面；
- 八个与舵盘同轴的通孔；
- 中央输出轴 / 中心螺钉工具避让孔；
- 法兰外缘的承力壁和圆角；
- 螺钉头或螺母的装配方向；
- HA8 输出轴中心、腿杆关节中心和法兰中心的同轴关系；
- 侧视剖面，明确金属舵盘、法兰、腿杆本体的层叠关系。
+
本阶段不应画出未经确认的螺钉长度、螺纹有效深度、腿杆最终孔距或盲孔深度。它们应在图中标为“��实测 / 待与总装 STEP 复核”。
+
### 5.3 背面被动支撑
+
- HA8 背面中心 M3 只用于连接被动支撑轴或支撑座。
- 被动侧应使用金属隔套、法兰轴承或耐磨衬套。
- 普通打印孔不能直接作为高负载旋转轴承面。
- 需要留出垫片或隔套调整轴向间隙，不能用 HA8 壳体承受轴向预紧。
+
## 6. 仍然不能直接锁死的尺寸
+
这些项目必须用官方 STEP、原始总装或实物确认，不能从网页示意图猜测：
+
- HA8 两侧安装耳孔的精确中心距和相对输出轴偏置；
- HA8 输出轴中心到安装基准面的精确距离；
- 官方金属舵盘的实际螺钉规格、有效螺纹深度和装配工具空间；
- 遥想星空原始腿杆关节端最终孔位、端面厚度和法兰外轮廓；
- 输出转接法兰的孔径补偿和沉孔/螺母槽形式；
- 背面被动支撑轴、轴承或衬套型号、外径、长度和轴向间隙；
- HA8 线束出口方向、插头尺寸和最小弯曲半径；
- 原始整机绝对装配坐标和四个关节与车身的最终安装关系。
+
## 7. 本阶段 FreeCAD 建模顺序
+
1. 导入官方 HA8 本体 STEP。
2. 导入官方 25T 八孔金属舵盘 STEP。
3. 导入遥想星空原始大腿 / 小腿端部 STEP 或根据总装截面建立腿杆端面参考。
4. 以 HA8 输出轴为关节基准轴，将金属舵盘与腿杆端部法兰同轴叠合。
5. 在腿杆端部建立八孔通孔和中央工具避让孔。
6. 再建立 HA8 两侧耳外固定支架和背面被动支撑。
7. 先检查螺钉装入方向、法兰贴合、线束空间和关节扫掠，再复制到镜像腿。
8. 通过 FreeCAD 截面和干涉检查后，才导出 STEP/STL。

## 9. 结论
+
这次的设计重点不是再增加一个孤立转接盘，而是修改遥想星空腿杆关节端：让腿杆端部本身带有与官方金属舵盘相匹配的法兰和八孔接口。HA8 本体由侧耳支架固定，腿杆通过金属舵盘与端部法兰传递扭矩，背面再用 M3 被动支撑保持同轴。
+
在腿杆最终孔位、HA8 精确基准距离、螺钉规格和被动支撑件确认前，这份资料和生成图只能作为 FreeCAD 结构评审基线，不能直接作为最终加工图或直接打印承力件。
