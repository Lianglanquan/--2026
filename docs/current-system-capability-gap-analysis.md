# 当前系统能力与缺失能力分析

审计日期：2026-09-26。范围包括主仓库、ROS 2 工作区、C Board 固件、部署脚本、
仿真测试、任务书附件和小智官方上游。未连接真机；本机也无法解析历史报告中的
`wheelbot-pi` SSH 别名，因此以下结论严格区分代码存在、自动测试和真机验收。

## 开发前基线

### 已完成或可直接复用

- C Board 已有 WB v1 CRC 二进制命令/状态协议、USB CDC 流解析、QD4310/HA8 接口和
  Raspberry Pi ROS bridge；这些层不需要重写。
- ROS 2 Jazzy 工作区已有 IMU、轮速里程计、EKF、YDLIDAR X2、SLAM Toolbox、URDF/TF
  与可组合启动文件，适合作为 Nav2 的输入边界。
- `/cmd_vel` 到轮 RPM 的转换已存在，但默认关闭，符合“标定后才允许运动”的安全原则。
- 仓库已有 MuJoCo 名义模型和自动检查，可继续承担纯软件回归，不等同于真机标定。

### 部分完成但未形成闭环

- 定位和建图代码存在；文档记录过 ROS 双机通信，但没有本轮可复现的真实地图、定位
  质量报告和 Nav2 `NavigateToPose` 验收证据。
- 轮半径、轮距、轮方向、雷达外参、机器人 footprint 和语义目标点仍是占位或未标定值。
- 开发前 C Board 命令路径没有命令年龄超时，USB 失联可能保留最后轮速。
- 历史文档描述了 ESP32 自研语音/串口固件，但仓库实际没有 `firmware/esp32_s3` 源码，
  文档与代码不一致。

### 开发前完全缺失

- 小智官方固件基线及 WheelBot 专用板型。
- 任务级 MCP 工具、Mission Manager、统一任务生命周期、幂等请求、持久化、取消/返航。
- 小智/网页可调用的机器人任务 API，以及机器人状态到 Web/语音层的统一数据源。
- Nav2 action 到任务状态机的适配。
- 机械臂高层服务接口；机械臂、相机、LeRobot、VLA 代码与运行环境本仓库均未提供。

## 本次增量完成

- 按固定上游提交导入官方 `78/xiaozhi-esp32`，新增独立 `wheelbot-s3-audio` 板型；没有
  修改其他官方板型。
- 新增五个高层 MCP 工具：语义导航、取物、返航、查询状态、取消任务。模型无法通过
  这些工具直接提交速度、电机或关节指令。
- 新增 ROS 2 `wheelbot_mission`，统一 `PENDING` 到完成/失败/取消的状态机，提供唯一
  mission ID、request ID 幂等、单任务仲裁、异常重启恢复和 JSON 持久化。
- Mission Manager 使用标准 Nav2 `NavigateToPose` action；取物到达后只发布机械臂高层
  请求，等待明确结果后才允许返航。
- 新增带 Bearer token、请求大小限制和输入校验的 REST API，供小智和未来 Web 平台
  共享同一真实任务状态。
- 新增可直接使用的 Web Mission Console、有序事件长轮询和小智反馈 webhook；反馈文本已按
  任务阶段统一生成，实际语音播放仍需要所用小智服务端适配器完成 TTS/`notify` 转发。
- 增加导航/机械臂阶段超时以及 C Board 状态新鲜度、链路和 fault mask 安全门槛；异常时取消
  下游动作并终止任务。
- 修复幂等边界：相同 request ID 的不同载荷会被拒绝，重复返航不会误取消后来创建的新任务。
- C Board 新增 200 ms command-age watchdog；超时后进入 idle、取消 HA8 目标、停止并禁用
  轮电机，同时在状态 fault bit 7 报告超时。
- 语义点默认全部 `commissioned: false`；未完成地图坐标标定时，真实导航请求会明确失败，
  不会使用零坐标误动作。

## 仍未完成及阻塞条件

- 必须在真实机器人上标定轮参数、雷达外参、footprint 和语义点，并准备 Nav2 参数与地图。
- 必须在架空轮子的台架上实测拔掉 USB 后 200 ms 自动停车；主机单元测试不能替代真机验收。
- 必须在 ESP-IDF 6.1 环境构建并烧录，验证 INMP441、MAX98357A、唤醒、官方云端和 MCP。
- 主仓库的 DJI 子模块固定提交已从上游消失；当前 checkout 退回到上游 master，需仓库
  所有者决定重新固定可获取提交或改为受控 vendor 快照。
- 机械臂服务目前只有明确的话题契约，不包含机械臂/VLA 实现，这是本轮刻意保留的边界。
- 主动语音播报 webhook 与标准中文反馈内容已实现；仍需提供实际小智服务端地址、设备身份和
  TTS/音频托管方式，完成官方 `notify` 的现场联调。

## 不应重新实现

- 不重写 C Board 电机与状态协议、ROS bridge、EKF、SLAM Toolbox 或小智官方网络/音频栈。
- 不把自然语言直接映射为 `/cmd_vel`、RPM 或机械臂关节动作。
- 不在未经测量时虚构机器人几何、语义坐标或“真机已经导航成功”的结论。
